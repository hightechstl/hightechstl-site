# Lanterns Below Marrow Hill — Quick Start

## What you need
- Exactly **2 players**
- One phone, iPad, or laptop with access to the Adventure Nights portal
- Optional printable pack: map, role sheets, clue deck, and endings
- About **45–60 minutes**

## Best format
Because the **web portal is the main play surface**, this package is built as:
1. **JSON** for game content and browser logic
2. **SVG** for map/tokens so they stay sharp on phones, tablets, and print
3. **Print-ready HTML** files that can be saved as PDF from any browser

This is more flexible than starting with PDF-only assets, and it still gives you easy download/print support.

## Setup
1. Open the adventure in the portal.
2. Seat 1 chooses **The Wickbearer**.
3. Seat 2 chooses **The Stone Listener**.
4. Read the shared introduction aloud.
5. Keep the hint file closed unless you get stuck.
6. If printing, place the map between both players and keep private role sheets separate.

## Core play loop
For each scene:
1. Read the **shared prompt** aloud.
2. Each player reads their **private prompt** silently.
3. Discuss what to do next for **2–4 minutes**.
4. Reveal any newly unlocked clue cards.
5. Complete the scene action.
6. Advance when the success condition is met.

## If players disagree
- Each player states **one reason** for their preferred action.
- Each player states **one concern** about the alternative.
- If still tied, choose the option that reveals more truth.

## When to use hints
Use Hint 1 first. If still stuck after two minutes, use the next hint.

## End condition
After Scene 4, make the final choice together and read the matching ending aloud.
