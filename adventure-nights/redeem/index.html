How It Works

Buy first, create the account later.

  1. Buy Quick-Play or Deluxe on J2 Crafts.
  2. Shopify sends the static ZIP download.
  3. The backend records an entitlement for the checkout email.
  4. When you sign in with that email, the adventure appears in your library.
  5. If email matching fails, redeem the backup code from the order email.
